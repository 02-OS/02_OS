# 02_OS

02_OS is a local-first developer operating system. The desktop is GNOME. The agent runtime indexes a Git repository on the machine and speaks the Model Context Protocol to a coding agent.

There is no telemetry and no mandatory account. The image is built with archiso. `ID_LIKE=arch` stays. The operating system name is 02_OS.

The boot animation is the Zero Portal. These pages do not change that motion.
