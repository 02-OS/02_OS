# Download

The published download is the latest GitHub release of [02-OS/02_OS](https://github.com/02-OS/02_OS/releases). These pages do not replace that download and do not publish a new image.

Build an image on a machine with at least 40 GiB free by running `./build.sh`. GitHub-hosted runners cannot produce the image. A pull request does not start an image build.

Keep the retained images `2026.09.26`, `2026.10.01`, and `2026.10.06`.
